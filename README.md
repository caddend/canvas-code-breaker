# Кодовый взломщик

Браузерная логическая игра-головоломка по мотивам классической настольной игры **Mastermind** («Быки и коровы»). Задача игрока — вычислить скрытый 4-значный цветовой код за 8 попыток с помощью подсказок.

Вся игра написана на чистом JavaScript и HTML5 Canvas без внешних библиотек и зависимостей.

---

## Быстрый запуск

Сборка не требуется. Достаточно открыть проект в любом современном веб-браузере.

### Вариант 1. Прямое открытие
Дважды кликните по файлу `index.html` или откройте его через меню браузера (**Ctrl + O** / **Cmd + O**).

### Вариант 2. Локальный статический сервер
При желании можно запустить локальный сервер из каталога проекта:

- С помощью **Python 3**:
  ```bash
  python -m http.server 8080
  ```
- С помощью **Node.js (npx)**:
  ```bash
  npx serve .
  ```

После запуска перейдите по адресу [http://localhost:8080](http://localhost:8080) (или порту, указанному сервером).

## Правила игры

1. Компьютер случайным образом загадывает последовательность из **4 цветов** (цвета могут повторяться). Доступно 6 оттенков: красный, зеленый, синий, желтый, фиолетовый и бирюзовый.
2. У вас есть **8 попыток**, чтобы взломать код.
3. В нижней палитре нажимайте на цветные круги, чтобы составить комбинацию из 4 элементов.
4. Нажмите кнопку **«ОТПРАВИТЬ»**, чтобы проверить предположение (кнопка **«СТЕРЕТЬ»** отменяет последний выбранный цвет).
5. Справа от каждого ряда появляются индикаторы-подсказки:
   - **Красная точка** — один из цветов угадан точно (совпадает и цвет, и его позиция).
   - **Светло-серая точка** — цвет присутствует в коде, но находится на другой позиции.
   - **Пустой контур** — несовпадение.
6. Игра завершается **победой**, если вы полностью разгадали код (4 красные точки), или **поражением**, если попытки исчерпаны. Для перезапуска нажмите на финальную кнопку с результатом.
